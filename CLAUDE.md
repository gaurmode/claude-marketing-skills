## 🧠 How This Works

This project contains **62 marketing skills** organized in `skills/` and **10 agent persona definitions** in `agents/`. Each skill is a markdown file (`SKILL.md`) containing domain expertise, frameworks, checklists, and decision trees.

**Before performing any marketing task:**
1. Identify the relevant skill(s) from the index below
2. Read the `SKILL.md` file for that skill
3. Apply the frameworks and rules from the skill
4. Reference supporting files (scripts, references, templates) as needed

## 🛡️ Global Rules

1. **Read Before Acting**: Always read the relevant `SKILL.md` before performing a marketing task.
2. **No Fabrication**: Never invent statistics, case studies, or data. Use real frameworks and principles.
3. **Socratic Gate**: For complex or ambiguous requests, ask clarifying questions first.
4. **Clean Output**: Be concise, direct, and solution-focused. No over-explaining.
5. **Self-Document**: Document decisions and changes in relevant markdown files.
